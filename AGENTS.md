# BUILT repository instructions

- Read [the editorial process](docs/EDITORIAL_PROCESS.md) before changing the catalogue or artwork.
- Start from the latest `main` and use a pull request for catalogue changes. Keep research candidates in `data/candidates.json` and completed, reviewed exhibits in `data/trmnl.json`.
- Preserve the TRMNL installation ID and verify the polling URL, Node Serverless language and custom settings after commits from TRMNL. Import the repository configuration before saving a new plugin instance in the TRMNL editor.
- Run the catalogue and rotation checks and review the relevant device previews before merging.
